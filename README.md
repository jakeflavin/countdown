# Countdown

A countdown timer built for focus: pick a duration or a target time and the clock takes
over the screen, over a scene that makes it worth looking at.

## What it does

- **A full-screen clock.** The time is the whole page — no chrome competing with it.
- **Duration or target.** Count down five minutes, or count down to 3pm.
- **Scenes.** Video backdrops with a matching palette, so the numbers stay legible against
  whatever is moving behind them.
- **Custom themes.** Build one from a gradient, or from your own image — the text, surface
  and border colours come with it already proven to read.
- **An alarm** when it reaches zero, and a share link that carries the settings.

## Running it

```
npm install
npm run dev
```

`npm run lint` and `npm run typecheck` are the checks CI runs. `npm run build` produces the
`dist/` that the directory publishes.
